# Code of conduct

Be respectful and stay on topic. Harassment, personal attacks and spam are
removed, and repeat offenders are blocked. Disagreements about code are
settled with evidence — a reproduction, a measurement, a reference.

To report a problem, use GitHub's "Report content" on the comment or issue,
or send a note through the feedback box at purrwall.xyz (include a way to
reach you if you want an answer).
